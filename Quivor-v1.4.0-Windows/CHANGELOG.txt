Version 1.4.0 (2026-01-25)
═══════════════════════════════════════════════════════════════════

🎉 NEW FEATURES

  ⌨️  Keyboard Shortcuts
      ✓ Full keyboard control for video playback
      ✓ Customizable shortcuts in Settings
      ✓ Default shortcuts:
        - Space/K: Play/Pause
        - ←/J: Seek Backward
        - →/L: Seek Forward
        - ↑/↓: Volume Control
        - M: Toggle Mute
        - F: Toggle Fullscreen
        - N/P: Next/Previous Video
      ✓ Focus management for keyboard events
      ✓ Visual feedback for active shortcuts

  ⏱️  Subtitle Synchronization
      ✓ Adjust subtitle timing per video
      ✓ Quick adjustment buttons:
        - -5s: Delay by 5 seconds
        - -0.5s: Delay by 0.5 seconds
        - Reset: Back to 0
        - +0.5s: Speed up by 0.5 seconds
        - +5s: Speed up by 5 seconds
      ✓ Per-video offset storage
      ✓ Automatic loading of saved offsets
      ✓ Real-time subtitle adjustment
      ✓ Visual offset indicator

  🎬 Adjustable Seek Duration
      ✓ Choose from 5 duration options:
        - 5 seconds (precise navigation)
        - 10 seconds (default)
        - 15 seconds (moderate skips)
        - 30 seconds (large skips)
        - 60 seconds (very large skips)
      ✓ Applies to keyboard shortcuts
      ✓ Applies to seek buttons
      ✓ Dynamic icon updates showing current duration
      ✓ Settings persist across sessions

  📝 Video Notes (Udemy-Style)
      ✓ Add timestamped notes while watching
      ✓ Automatic timestamp capture
      ✓ Click notes to jump to that moment
      ✓ Per-video note storage
      ✓ Beautiful side panel UI (350px)
      ✓ Add note dialog with text input
      ✓ Delete notes functionality
      ✓ Empty state UI
      ✓ Formatted timestamps (HH:MM:SS or MM:SS)
      ✓ Notes sorted by timestamp
      ✓ Persistent storage in database

🐛 BUG FIXES

  ✓ Fixed keyboard shortcuts ProviderNotFoundException

  ✓ Fixed deprecated withOpacity calls (now using withValues)
