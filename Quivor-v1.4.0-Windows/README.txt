📋 WHAT'S NEW IN v1.4.0

  ⌨️  Keyboard Shortcuts (Customizable)
      - Full keyboard control for video playback
      - Customize all shortcuts in Settings
      - Space, Arrow keys, and more!

  ⏱️  Subtitle Synchronization
      - Adjust subtitle timing per video
      - Quick buttons: -5s, -0.5s, +0.5s, +5s
      - Settings saved automatically

  🎬 Adjustable Seek Duration
      - Choose from 5, 10, 15, 30, or 60 seconds
      - Works with keyboard and buttons
      - Icons show current duration

  📝 Video Notes (Udemy-Style)
      - Add timestamped notes while watching
      - Click notes to jump to that moment
      - Per-video note storage
      - Beautiful side panel UI

🚀 INSTALLATION

  1. Extract all files to a folder
  2. Run video_player.exe
  3. Enjoy!

  Note: Keep all DLL files in the same folder as the .exe

═══════════════════════════════════════════════════════════════════

⌨️  KEYBOARD SHORTCUTS (Default)

  Playback:
    Space / K         Play/Pause
    ← / J             Seek Backward
    → / L             Seek Forward
    N                 Next Video
    P                 Previous Video

  Volume:
    ↑                 Volume Up
    ↓                 Volume Down
    M                 Toggle Mute

  Display:
    F                 Toggle Fullscreen

  💡 Tip: Customize all shortcuts in Settings!

🎯 QUICK START

  1. Open Video/Folder
     - Click "Open Video" or "Open Folder" on home screen
     - Or drag & drop video files

  2. Create Playlist
     - Click "Create Playlist"
     - Add videos from your computer
     - Name your playlist

  3. Play & Enjoy
     - Click on any video to start playing
     - Use keyboard shortcuts for control
     - Add notes while watching

═══════════════════════════════════════════════════════════════════

📚 USING VIDEO NOTES

  1. While watching, click the Notes button (📝)
  2. Click "Add Note" button
  3. Type your note and save
  4. Click any note to jump to that timestamp!

  Perfect for:
    - Taking course notes
    - Marking important scenes
    - Creating video outlines
    - Study and review

🐛 TROUBLESHOOTING

  Problem: App won't start
  Solution: Install Visual C++ Redistributable 2015-2022
           (included in Windows Update)

  Problem: Video won't play
  Solution: Check if video codec is supported
           Try converting to MP4 (H.264)

  Problem: Keyboard shortcuts not working
  Solution: Click on the video player to focus it

  Problem: Subtitles out of sync
  Solution: Use Subtitle Sync feature in subtitle menu
